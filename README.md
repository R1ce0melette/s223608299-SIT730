##Code repo for Task 2.1P - SIT730 Embedded System

Devices used:
•	Arduino Nano 33 IoT
•	Temp/Humid sensor DHT11 – 3 pins
•	Light sensor BH1750FVI – 5 pins

| DHT11    | Arduino |
| -------- | ------- |
| GND  | GND    |
| VCC | 3V3     |
| Signal    | D7    |

| BH1750FVI	| Arduino |
| -------- | ------- |
| VCC |	3V3 |
| GND	| GND |
| SCL	| A5 |
| SDA |	A4 |
| ADD |	No connection |

Lib used:  
- DHT11.h
- BH1750FVI.h
- SPI.h
- WiFiNINA.h
- ThingSpeak.h
