# LED control using voice command
## Hardware
- Raspberry Pi 4
- USB microphone
- LED
- 1 220 Ohm resistor
## Software
- Vosk Speech Recognition small model
- PyAudio
- GPIO lib

Put the model in the same directory with the script. Download and unzip
Link to the vosk model [download link](https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip)
